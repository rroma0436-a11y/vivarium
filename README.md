# Затишний віварій — v0.1

Затишна гра-ферма на Godot 4.5 (2.5D: 3D-персонажі на живих відеофонах).

## Що є у v0.1
- Дві локації: **Подвір'я** (живий відеофон) і **Кімната** з тераріумом.
- Цуценя **Бім**: гуляє, їсть із миски, радіє, коли його гладять.
- Гекон **Лимончик**: треба тримати 28–32 °C лампою і годувати цвіркунами.
- Робот-помічник **Beep** літає за дотиком.
- **Дідусь Петро** дає завдання першого дня. За виконані завдання дають монетки.
- Гра зберігається автоматично.

## Збірка APK
GitHub → вкладка **Actions** → **Build Android APK** → **Run workflow**.
Коли збірка закінчиться, APK буде внизу сторінки, у розділі **Artifacts**.

## Структура
- `scripts/game.gd` — стан гри, завдання, збереження (autoload `Game`)
- `scripts/main.gd` — сцена, локації, дотики
- `scripts/hud.gd` — інтерфейс
- `scripts/puppy.gd`, `beep.gd`, `terrarium.gd` — персонажі
- `assets/` — фони, кадри цуценяти, шрифти
